# Novedades

Aquí se publican los cambios de SIHSALUS que modifican lo que el usuario ve o
hace.

Cada nota indicará:

- versión y fecha;
- módulos afectados;
- cambio visible;
- acción requerida, si existe;
- limitaciones conocidas.

Las notas para usuarios no incluyen detalles de servidores, credenciales,
permisos internos, identificadores técnicos ni incidentes de seguridad.

## Portal de ayuda — versión inicial

Se creó el portal de ayuda de SIHSALUS con guías iniciales para identificación,
citas, triaje, consulta externa, Farmacia y Laboratorio.
