# Farmacia

Farmacia permite buscar recetas y registrar la dispensación autorizada.

1. Abra **Farmacia**.
2. Busque al paciente por nombre o identificador.
3. Revise **Recetas activas** o **Todas las recetas**, según corresponda.
4. Confirme paciente, prescriptor, medicamento e instrucciones.
5. Abra la receta y registre únicamente lo que realmente se dispensó.
6. Confirme el resultado antes de atender otra receta.

No modifique una indicación clínica para resolver una inconsistencia. Si la
receta no es clara o no puede confirmarse, use el canal autorizado del
establecimiento.
