# Identificación y registro del paciente

Use esta guía para encontrar la historia correcta o registrar a una persona que
aún no existe en SIHSALUS.

1. Busque antes de crear un registro.
2. Use los datos disponibles: historia clínica, código temporal, documento,
   nombres y fecha de nacimiento.
3. Compare cuidadosamente las posibles coincidencias.
4. Si no existe una coincidencia, registre únicamente los datos confirmados.
5. Revise el resumen del paciente antes de continuar con la atención.

El DNI no es el único medio de identificación. Si la persona no puede
identificarse o comunicar sus datos, use el flujo autorizado para pacientes no
identificados y registre al responsable o informante cuando esté disponible.

No invente documentos, fechas, direcciones ni datos de contacto. Si encuentra
posibles duplicados, detenga el registro y solicite su conciliación.
