# Consulta externa

Use Consulta externa para registrar la atención clínica de una consulta activa.

1. Confirme el paciente y la consulta activa.
2. Revise la información disponible de triaje.
3. Registre el motivo de consulta y la evaluación correspondiente.
4. Registre los diagnósticos, el plan y las indicaciones.
5. Agregue las órdenes que correspondan.
6. Verifique que cada sección se haya guardado antes de finalizar.

Las acciones visibles dependen de su perfil. No finalice la consulta mientras
existan registros pendientes o un guardado de resultado incierto.
