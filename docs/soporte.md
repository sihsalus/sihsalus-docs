# Ayuda y soporte

Si tiene un problema:

1. Anote la fecha y hora aproximadas.
2. Identifique el módulo y la acción que intentaba realizar.
3. Copie solamente el mensaje visible que no contenga datos del paciente.
4. Verifique el estado de conexión.
5. Si una acción clínica pudo haberse guardado, revise el registro antes de
   volver a ejecutarla.
6. Comuníquese mediante el canal autorizado de su establecimiento.

!!! danger "Proteja al paciente"

    No envíe nombres, documentos, números de historia clínica, recetas,
    resultados, fotografías ni capturas con información de pacientes.

Para reportar una posible vulnerabilidad, escriba a
`sihsalus@pucp.edu.pe` sin incluir detalles sensibles y solicite un canal
privado.

Una emergencia clínica debe seguir los procedimientos asistenciales del
establecimiento; este canal es solamente para soporte del sistema.
