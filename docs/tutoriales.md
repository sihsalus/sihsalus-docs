# Tutoriales

Las guías interactivas muestran paso a paso dónde encontrar las funciones
principales de SIHSALUS.

Los tutoriales propios de SIHSALUS se habilitarán progresivamente. Mientras
tanto, use las guías escritas de este portal.

Un tutorial disponible en producción debe ser solo de navegación: no debe crear,
editar ni eliminar información clínica. Tampoco reemplaza la capacitación ni
los protocolos del establecimiento.

Los videos se publicarán como complemento, con datos sintéticos, subtítulos,
versión probada y una guía escrita equivalente disponible en la LAN.
